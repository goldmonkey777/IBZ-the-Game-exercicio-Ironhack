# IBZ-the-Game-exercicio-Ironhack
IBZ the GAME is a browser-based JavaScript game developed as a final project for the Ironhack Web Development Bootcamp (Module 1). The project focuses on DOM manipulation, game loops, collision detection, and state management, using only HTML, CSS, and vanilla JavaScript.

## Deploy (GitHub Pages)
- O workflow `.github/workflows/deploy-pages.yml` faz deploy automático a cada push em `main`.
- Para ativar: no repositório, **Settings → Pages → Build and deployment → Source**: escolha **GitHub Actions**.
- O jogo ficará em: `https://<seu-usuario>.github.io/IBZ-the-Game-exercicio-Ironhack/`
